# Contributing to MyPoll

- ## To contribute
    - Write your update and then write a descripive summary of your commit. If the commit is linked to an issue, link the PR to the issue.


- ## Standards
    - Api functionality goes in the `pages/api` folder with a seperate file per API route.
    - Code is formatted with prettier, nothing else.
    - Code follows the CKAN standard set listed [here](https://docs.ckan.org/en/2.9/contributing/javascript.html)
